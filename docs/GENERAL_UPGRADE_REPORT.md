# General agent and 3D upgrade — October 5, 2026

Only Giotty/Jarvis was modified. The update is installed as 0.7.0. This is **not a full acceptance pass**; the detailed Blender failures and actual artifacts are in [Blender verification](BLENDER_PIPELINE_VERIFICATION.md).

1. The fixed product-oriented task hierarchy, specification extraction and chart assumptions were replaced by semantic entities/relationships, model-derived required/optional artifacts and generic dependency graphs. Production 3D does not select geometry recipes by object name.
2. GoalSpec represents the user's objective, entities/relationships, scope, timeframe, evidence/precision, desired artifacts, dependencies and quality requirements. Routing classification returns it with a task profile. Model JSON is normalized/validated with bounded repair. Execution preserves successful independent branches and records incomplete requirements.
3. Five real unrelated research attempts were run: Jupiter/moons incomplete (~176 s, earlier path); Porsche completed (~48 s, earlier path); reactor incomplete (~794 s, semantic path); Maple Leafs incomplete (~164 s, earlier path); CPUs incomplete (~426 s, semantic path, unsupported fact failed evidence repair). These were not all rerun after the latest fixes and are **not five generalization passes**. Exact source/value matching now rejects unsupported quantitative claims; blocked pages and malformed/inaccurate model synthesis still limit completion.
4. NVIDIA's artificial 300/day and session routing caps are removed. Request counts are diagnostic; corrupt/unwritable diagnostic storage cannot block inference. Gemini retains its separately configured safety budget.
5. Real fallback causes remain authentication, unavailable/capability-mismatched models, actual 429/server errors, timeouts, empty/malformed output, local/privacy requirements, free-only restrictions and health cooldowns. No claim of unlimited vendor quota is made.
6. Detected RTX 4060 memory: **8,188 MiB**; system RAM approximately **15.85 GiB**.
7. TRELLIS did not meet the accepted 12 GB VRAM/32 GB RAM prerequisites. The user accepted this result. No forced installation occurred.
8. WSL package 2.6.3 was detected, but working Linux distribution execution was not established; Docker and CUDA toolkit/runtime deployment were not installed/validated. Driver compatibility alone does not establish a usable NIM deployment.
9. Optional future adapter contracts were tested for base:text, large:text, large:image and combined text/image variant selection using a fixture endpoint, not live TRELLIS.
10. **No TRELLIS variant actually runs here.** Readiness, inference, cancellation, embedded GLB validation and optional hosted endpoint routing remain architecturally available.
11. Blender text-to-3D created actual artifacts through structured design planning and general stages. Automatic quality remains unapproved across the requested unrelated tests. A separate assisted GPU provides a useful example without being labelled an autonomous planner pass.
12. Reference images were actually researched/downloaded/analyzed to guide original Blender designs. Native TRELLIS image-to-3D was not run on incompatible hardware.
13. Blender refinements used real transforms, meshes, modifiers, arrays/Boolean, curves/lathe, materials, UVs and multi-view Cycles rendering. Generic problems in axes, material persistence, modifier order, staging/framing and partial replacement recovery were corrected.
14. Actual per-object category scores and unscored failures are recorded in [the score table](BLENDER_PIPELINE_VERIFICATION.md). None of the automatic seven-subject results is being called a HIGH/ULTRA pass.
15. Actual BLEND/GLB/STL/PNG files exist; GLB headers/resources were validated and Three.js asset-ID loading was checked. Printable/manifold geometry and physical dimensions are not universally certified.
16. New saved model workspaces reopened through fresh Library and Blender service instances. The earlier saved GPU workspace was recovered from its prior snapshot when its Library entry could not be found, with the original asset files retained.
17. Remaining limits: free provider latency/errors, incomplete reference coverage, unsupported research claims, poor automatic geometry in several subjects, approximate materials, incomplete local NIM compatibility, and physical microphone availability. Secrets stay encrypted; voice and safety settings are retained. No other GitHub repository was modified.
