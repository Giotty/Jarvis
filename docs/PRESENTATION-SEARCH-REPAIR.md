# JARVIS 0.5.2

The presentation X now records dismissal before pausing playback, cancels its current narration, and removes the overlay. Delayed updates to that session cannot reopen it. BRIEFING and explicit library opens still restore it; a new presentation can open normally. Existing files and saved copies are retained. The HUD styling, floating file design, voice settings and safety confirmations are unchanged.

Background research now combines DuckDuckGo HTML, Bing web/news RSS and Wikipedia public search. Bounded focused queries and generic word-order variants recover from engines broadening a specific request. Results are ranked for subject relevance, deduplicated and limited per domain. News publisher redirects are unwrapped to their actual source URLs. Failed providers do not prevent other indexes from contributing; cancellation remains effective.

Each search reads up to six candidate pages and up to four relevant discovered links under a 22-second overall deadline, returning up to six sources. Link selection covers missing query aspects. Extraction preserves table rows, relevant sections beyond the previous cutoff and bounded public JSON/JSON-LD content without running scripts. The organizer receives longer evidence excerpts. Only cited sources are attached to visual files, avoiding exhaustion of the workspace source cap by unrelated reads. Public-address validation, DNS pinning, size limits, attribution and untrusted-data treatment remain enabled.

Verification: eight new search/extraction/source-budget regression tests; existing JavaScript regressions; lint, TypeScript and production build. Live background requests retrieved official Canadiens roster/dated practice articles, other sports publishers and unrelated movie sources without desktop actions. The actual local-model full-biography test remained incomplete within its task budget and used attributed source previews, so complete analysis is not guaranteed. Some public sites block automated access; unavailable or unverified facts must remain explicit. No paid APIs, access bypass or visible browser research were added.

The packaged smoke check clicks the presentation X with real pointer input, injects delayed workspace updates, checks that the overlay and dimming remain gone, opens HUD settings and explicitly reopens BRIEFING in an isolated profile. Release packaging verifies application metadata and every packaged source file against its build snapshot.
